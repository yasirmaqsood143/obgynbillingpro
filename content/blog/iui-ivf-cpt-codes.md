Fertility billing is cycle-based: a single IUI or IVF cycle generates a sequence of clinical, laboratory and procedural services over several weeks. Knowing which code describes each step — and how payers want them reported — is the foundation of clean fertility billing. This reference walks through an IUI cycle and an IVF cycle step by step.

## IUI cycle coding

| Step | Typical code(s) |
|---|---|
| Consultation / planning visit | Office E/M (`99202`–`99215`) |
| Baseline and monitoring ultrasound | `76830` (transvaginal) or `76857` (pelvic, limited), per documentation |
| Hormone labs | Lab codes (if performed in-house) |
| Sperm washing | `58323` |
| Intrauterine insemination | `58322` |
| Intracervical insemination (less common) | `58321` |

Ovulation-induction medications are usually covered — if at all — under the pharmacy benefit.

## IVF cycle coding

### Stimulation and monitoring

Office visits, transvaginal ultrasounds and hormone levels during stimulation, coded per encounter — or included in a cycle case rate, depending on the payer.

### Oocyte retrieval

| Service | Code |
|---|---|
| Follicle puncture for oocyte retrieval, any method | `58970` |
| Ultrasound guidance for aspiration of ova | `76948` |
| Anesthesia | Anesthesia codes, billed by the anesthesia provider |

### Embryology laboratory

| Service | Code |
|---|---|
| Oocyte identification from follicular fluid | `89254` |
| Culture of oocyte(s)/embryo(s), less than 4 days | `89250` |
| Culture with co-culture | `89251` |
| Insemination of oocytes (conventional) | `89268` |
| Assisted oocyte fertilization, microtechnique (ICSI), ≤10 oocytes / >10 oocytes | `89280` / `89281` |
| Extended culture, 4–7 days | `89272` |
| Assisted embryo hatching | `89253` |
| Biopsy for preimplantation genetic testing, ≤5 embryos / >5 embryos | `89290` / `89291` |
| Preparation of embryo for transfer | `89255` |
| Sperm isolation (simple / complex) | `89260` / `89261` |

### Transfer

| Service | Code |
|---|---|
| Embryo transfer, intrauterine | `58974` |
| Gamete, zygote or embryo intrafallopian transfer (rare) | `58976` |

## S-codes and case rates

Some commercial payers and fertility benefit managers require **HCPCS S-codes** that bundle a cycle into a case rate instead of component CPT codes. Examples include `S4011` (in vitro fertilization procedure), `S4015` (complete IVF cycle, case rate) and `S4016` (frozen IVF cycle, case rate), among others. Medicare doesn't recognize S-codes, and payers that use them each define what's included. Bill component codes or S-codes exactly as each payer specifies — never both for the same services.

## Where coverage limits interact with coding

- **Diagnostic vs. treatment coverage.** Many plans cover infertility testing but exclude treatment. Diagnostic services must be coded as diagnostic, with the reason for evaluation.
- **Lifetime maximums.** Cycle counts or dollar limits mean benefits must be checked before each cycle.
- **Partner services.** Semen analysis and sperm processing may belong on the partner's insurance.
- **Storage.** Annual storage fees are frequently non-covered and billed to the patient.
- **Mandates.** State mandates apply to fully insured plans, not self-funded plans.

See [infertility & REI billing](/infertility-rei-billing) for benefit verification.

## Diagnosis coding matters too

- `N97.-` — female infertility, by cause
- `N46.-` — male infertility
- `Z31.-` — encounters for procreative management (including `Z31.83` for an assisted reproductive fertility procedure cycle and `Z31.84` for fertility preservation)
- Underlying conditions (`E28.2` PCOS, `N80.-` endometriosis, tubal factors) when they're the reason for evaluation or treatment

## Common IUI/IVF billing errors

1. Billing component codes to a payer that requires S-code case rates (or the reverse)
2. Missing `76948` ultrasound guidance with `58970`
3. Billing ICSI with the wrong tier
4. Storage billed per cycle instead of per year
5. Partner services on the wrong policy
6. Treatment started before benefits were verified

## Frozen embryo transfer cycles

Frozen embryo transfer (FET) cycles are now a large share of IVF activity, and they're coded differently from fresh cycles:

| Step | Typical code(s) |
|---|---|
| Endometrial preparation monitoring | Office E/M, transvaginal ultrasound, hormone labs |
| Thawing of cryopreserved embryo(s) | `89352` |
| Assisted hatching, if performed | `89253` |
| Preparation of embryo for transfer | `89255` |
| Embryo transfer | `58974` |

Payers that use case rates may require `S4016` (frozen IVF cycle, case rate) instead of component codes. Storage fees (`89342`) continue annually until embryos are used, donated or discarded — and are frequently patient responsibility.

## Fertility preservation cycles

Oocyte or embryo cryopreservation before cancer treatment follows the IVF retrieval and lab steps above, ending with cryopreservation (`89337` for oocytes, `89258` for embryos) instead of transfer. Use `Z31.84` (encounter for fertility preservation procedure) with the underlying condition, and check state mandates for iatrogenic infertility coverage — several states require it for fully insured plans.

## Documentation tips

- Record the number of oocytes retrieved and inseminated (ICSI tiers depend on count)
- Record the number of embryos biopsied (PGT tiers depend on count)
- Document culture duration (less than 4 days vs. extended culture)
- Note which partner each service relates to
