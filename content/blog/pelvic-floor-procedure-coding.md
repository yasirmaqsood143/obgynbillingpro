Pelvic floor reconstruction often involves several procedures in one operation — a vaginal hysterectomy, an apical suspension, anterior and posterior repairs, and a sling for stress incontinence. Coding that combination correctly requires knowing which procedures have **combination codes**, which are **separately reportable**, and which are **bundled**. Get it wrong in one direction and you undercode a long, complex case; get it wrong in the other and you've unbundled.

## Step 1: Identify every component performed

Read the operative note and list each procedure by compartment and purpose:

| Compartment / purpose | Typical procedures |
|---|---|
| Anterior (cystocele) | Anterior colporrhaphy, paravaginal repair |
| Posterior (rectocele) | Posterior colporrhaphy, perineorrhaphy |
| Apical (uterine or vault prolapse) | Vaginal hysterectomy, uterosacral or sacrospinous suspension, sacrocolpopexy |
| Enterocele | Enterocele repair |
| Stress incontinence | Midurethral sling, Burch urethropexy |
| Other | Mesh placement, cystoscopy, perineal body repair |

Only then choose codes.

## Step 2: Check for combination codes first

CPT includes combination codes that describe common pairings. Using them instead of separate codes is both more accurate and prevents unbundling denials.

**Colporrhaphy combinations:**

| Procedure | Code |
|---|---|
| Anterior colporrhaphy alone | `57240` |
| Posterior colporrhaphy alone | `57250` |
| Combined anterior + posterior | `57260` |
| Combined anterior + posterior + enterocele repair | `57265` |

**Vaginal hysterectomy combinations** (examples):

| Procedure | Code |
|---|---|
| Vaginal hysterectomy, ≤250 g, with removal of tubes/ovaries, with repair of enterocele | `58263` |
| Vaginal hysterectomy with colpo-urethrocystopexy | `58267` |
| Vaginal hysterectomy, ≤250 g, with repair of enterocele | `58270` |
| Vaginal hysterectomy with total or partial vaginectomy, with repair of enterocele | `58280` |
| Vaginal hysterectomy, >250 g, with removal of tubes/ovaries, with repair of enterocele | `58292` |
| Vaginal hysterectomy, >250 g, with repair of enterocele | `58294` |

Confirm full descriptors in the CPT codebook — the combinations are specific.

## Step 3: Code apical suspension

| Procedure | Code |
|---|---|
| Colpopexy, vaginal; extra-peritoneal approach (e.g., sacrospinous ligament fixation) | `57282` |
| Colpopexy, vaginal; intra-peritoneal approach (e.g., uterosacral ligament suspension) | `57283` |
| Colpopexy, abdominal (open sacrocolpopexy) | `57280` |
| Laparoscopic colpopexy (including robotic sacrocolpopexy) | `57425` |

When a laparoscopic sacrocolpopexy is performed with a laparoscopic supracervical or total hysterectomy, both are generally reported, subject to NCCI edits and payer policy.

## Step 4: Add incontinence procedures

- `57288` — sling operation for stress incontinence
- `51990` / `51992` — laparoscopic urethral suspension (Burch) / laparoscopic sling
- `51840` / `51841` — open Burch procedures

A sling performed for documented stress incontinence at the same session as prolapse repair is a separate procedure. Check NCCI edits; some code pairs need a distinct-procedure modifier.

## Step 5: Handle mesh and graft codes

`57267` is an **add-on** code for insertion of mesh or other prosthesis for repair of pelvic floor defect, **each site** (anterior, posterior compartment), vaginal approach. It's reported with specific primary repair codes per CPT instructions. Payer coverage for transvaginal mesh varies, and many payers have restrictive policies — verify before surgery.

## Step 6: Watch the bundles

- **Cystoscopy** to check bladder and ureters during these procedures is generally part of the primary procedure.
- **Perineorrhaphy** is included in posterior colporrhaphy.
- **Paravaginal repair** may be bundled with anterior colporrhaphy in some combinations — check edits.
- **Enterocele repair** is included in combination codes that list it; don't add `57268` separately.

## Modifiers for multiple procedures

- **`51`** — multiple procedures, applied by many payers' systems automatically to secondary procedures
- **`59` / X-modifiers** — only for distinct procedures that NCCI would otherwise bundle, with documentation
- **`22`** — for substantially increased work (prior repairs, dense scarring, unusual anatomy)
- **`62`** — co-surgeons, for example when a urogynecologist and colorectal surgeon perform a combined procedure for pelvic organ prolapse and rectal prolapse

## Worked example

**Operation:** vaginal hysterectomy (uterus 180 g) with bilateral salpingectomy, uterosacral ligament suspension, anterior and posterior colporrhaphy, and midurethral sling for stress incontinence. Cystoscopy confirmed ureteral patency.

**Coding considerations:**
- Vaginal hysterectomy with removal of tubes, ≤250 g → `58262` (check whether a combination code better describes the apical/enterocele work documented)
- Uterosacral ligament suspension → `57283`, subject to edits with the hysterectomy code
- Combined anterior/posterior repair → `57260`
- Sling → `57288`
- Cystoscopy → included, not separately reported
- Diagnoses → `N81.2`/`N81.3` (uterovaginal prolapse, incomplete/complete), `N81.1-` (cystocele), `N81.6` (rectocele), `N39.3` (stress incontinence)

Run the final combination through NCCI edits and the payer's policy before submission.

## Documentation tips for surgeons

- Name each compartment repaired and the technique
- Specify the apical procedure and approach
- Document mesh use and location
- State the indication for any procedure beyond routine (for example, cystoscopy for a separate finding)
- Note prior repairs, scarring or unusual difficulty if modifier `22` may apply

## Diagnosis coding for pelvic floor surgery

Accurate diagnosis codes support medical necessity for reconstructive surgery:

| ICD-10-CM | Description |
|---|---|
| `N81.1-` | Cystocele (midline, lateral, unspecified) |
| `N81.2` | Incomplete uterovaginal prolapse |
| `N81.3` | Complete uterovaginal prolapse |
| `N81.4` | Uterovaginal prolapse, unspecified |
| `N81.5` | Vaginal enterocele |
| `N81.6` | Rectocele |
| `N81.8-` | Other female genital prolapse (including perineocele and pelvic floor muscle wasting) |
| `N99.3` | Prolapse of vaginal vault after hysterectomy |
| `N39.3` | Stress incontinence (female) |
| `N39.46` | Mixed incontinence |

Code every compartment documented. A diagnosis for each repaired compartment makes the medical necessity of each procedure clear.
