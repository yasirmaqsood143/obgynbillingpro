## How to use this library

This reference lists the CPT and HCPCS codes we see most often in OB/GYN billing, grouped by type of service. Descriptors are summarized for readability — always confirm the full descriptor in the current CPT codebook, and check payer policies for coverage. Codes are valid for 2026 dates of service unless noted.

## Obstetric care (through December 31, 2026)

| Code | Summary |
|---|---|
| `59400` | Routine obstetric care incl. antepartum, vaginal delivery and postpartum care |
| `59409` / `59410` | Vaginal delivery only / including postpartum care |
| `59510` | Routine obstetric care incl. antepartum, cesarean delivery and postpartum care |
| `59514` / `59515` | Cesarean delivery only / including postpartum care |
| `59610` / `59612` / `59614` | VBAC: global / delivery only / including postpartum |
| `59618` / `59620` / `59622` | Cesarean after attempted VBAC: global / delivery only / including postpartum |
| `59425` / `59426` | Antepartum care only, 4–6 visits / 7 or more visits |
| `59430` | Postpartum care only |

**Starting January 1, 2027**, these codes are deleted and replaced by E/M visits plus new labor management (`59080`–`59083`) and delivery codes (`59431`, `59432`, `59502`, `59503`, `59504`). Details in our [2027 maternity transition guide](/resources/2027-maternity-transition). For billing guidance today, see [global maternity billing](/global-maternity-billing).

## Obstetric and gynecologic ultrasound

| Code | Summary |
|---|---|
| `76801` (+`76802`) | OB ultrasound, under 14 weeks, transabdominal, single (+ each additional gestation) |
| `76805` (+`76810`) | OB ultrasound, 14 weeks or more, transabdominal, single (+ each additional) |
| `76811` (+`76812`) | Detailed fetal anatomic evaluation (+ each additional) |
| `76813` (+`76814`) | Nuchal translucency measurement (+ each additional) |
| `76815` | OB ultrasound, limited (e.g., fetal heart, position, fluid) |
| `76816` | OB ultrasound, follow-up |
| `76817` | OB ultrasound, transvaginal |
| `76818` / `76819` | Biophysical profile with / without non-stress testing |
| `76820` / `76821` | Doppler velocimetry, umbilical artery / middle cerebral artery |
| `76830` | Transvaginal ultrasound, non-obstetric |
| `76856` / `76857` | Pelvic ultrasound, non-obstetric, complete / limited |
| `76831` | Saline infusion sonohysterography (with `58340`) |

Payers often apply frequency limits to `76805`, `76811` and `76816`, and require diagnoses that support the medical necessity of each study.

When a significant, separately identifiable problem is addressed at a preventive visit, a problem-oriented E/M may also be billed with modifier `25`.

## Hysterectomy

| Approach | ≤250 g | ≤250 g + adnexa | >250 g | >250 g + adnexa |
|---|---|---|---|---|
| Total laparoscopic | `58570` | `58571` | `58572` | `58573` |
| Laparoscopic supracervical | `58541` | `58542` | `58543` | `58544` |
| LAVH | `58550` | `58552` | `58553` | `58554` |
| Vaginal | `58260` | `58262` | `58290` | `58291` |

Abdominal: `58150` (total, with or without adnexa), `58180` (supracervical). There is no separate robotic code — robotic cases use the laparoscopic codes. See [GYN surgery coding](/gyn-surgery-coding) and our article on the [CPT code for robotic hysterectomy](/blog/cpt-code-robotic-hysterectomy).

## Pelvic floor surgery

`57240` (anterior repair), `57250` (posterior repair), `57260`/`57265` (combined repair), `57282`/`57283` (vaginal colpopexy), `57425` (laparoscopic colpopexy), `57288` (sling). More on our [urogynecology billing](/urogynecology-billing) page.
