## Why urogynecology billing is complex

Urogynecology — formally urogynecology and reconstructive pelvic surgery — sits between gynecology and urology. A typical practice performs reconstructive surgery for prolapse, anti-incontinence procedures, mesh complication management, office urodynamic testing, pessary care, and therapies such as bladder injections and neuromodulation.

The billing challenge is that many of these procedures are performed together and many are bundled with each other. A single surgical session might include a vaginal hysterectomy, an apical suspension, an anterior and posterior repair, and a midurethral sling. Coding that case correctly requires knowing which combinations have their own CPT codes, which are separately reportable, which are bundled under NCCI, and which modifiers each payer expects. Our team has spent more than eight years coding OB/GYN and pelvic surgery, and we read every operative note in full.

## Prolapse repair codes

| Procedure | CPT |
|---|---|
| Anterior colporrhaphy (cystocele repair) | `57240` |
| Posterior colporrhaphy (rectocele repair) | `57250` |
| Combined anterior and posterior colporrhaphy | `57260` |
| Combined A&P with enterocele repair | `57265` |
| Enterocele repair, vaginal | `57268` |
| Colpopexy, vaginal; extra-peritoneal (e.g., sacrospinous) | `57282` |
| Colpopexy, vaginal; intra-peritoneal (e.g., uterosacral) | `57283` |
| Colpopexy, abdominal (open sacrocolpopexy) | `57280` |
| Colpopexy, laparoscopic (incl. robotic) | `57425` |
| Paravaginal defect repair — open / vaginal / laparoscopic | `57284` / `57285` / `57423` |
| Insertion of mesh for vaginal repair (add-on) | `57267` |
| Colpocleisis | `57120` (Le Fort), `57110` |

**Vaginal hysterectomy with repairs** has its own combination codes — for example `58263` (with enterocele repair), `58267` (with colpo-urethrocystopexy), `58270` (with enterocele repair, uterus 250 g or less) and the larger-uterus equivalents. Using the combination code rather than billing the hysterectomy and the repair separately is a common correction we make. See our [GYN surgery coding](/gyn-surgery-coding) page for hysterectomy code tables.

## Incontinence procedures

- **`57288`** — sling operation for stress incontinence (e.g., midurethral sling)
- **`57287`** — removal or revision of sling
- **`51990`** / **`51992`** — laparoscopic urethral suspension (Burch) / laparoscopic sling
- **`51840`** / **`51841`** — open anterior vesicourethropexy or urethropexy (Burch)
- **`51715`** — endoscopic injection of implant material (urethral bulking)

When a sling is placed at the same session as prolapse repair, both are typically reportable with appropriate modifiers if the payer's edits require them — but intraoperative cystoscopy to confirm bladder integrity is usually bundled.

## Mesh complications

Mesh erosion, exposure and pain are a significant part of many urogynecology practices. Coding depends on approach — `57295` (vaginal), `57296` (open abdominal) and `57426` (laparoscopic) for prosthetic vaginal graft revision or removal, and `57287` for slings. The diagnosis should specify the complication using category `T83` codes for complications of genitourinary prosthetic devices, implants and grafts, with the appropriate encounter character.

## Office diagnostics and treatment

### Urodynamic testing

Complex urodynamics is reported by component, and each component is billed only when performed:

- `51725`/`51726`–`51729` — cystometrogram variations
- `51741` — complex uroflowmetry
- `51784` — EMG studies
- `51797` — intra-abdominal (rectal) voiding pressure, add-on

Professional and technical components (modifiers `26` and `TC`) apply when testing is performed in a facility or by a separate entity.

### Pessary management

Pessary fitting and insertion is `57160`; the pessary supply may be billed separately with HCPCS codes (for example `A4561` or `A4562`) where the payer allows. Follow-up visits for pessary cleaning and checks are typically billed with E/M codes when they meet the requirements.

### Bladder therapies

- **`52287`** — cystourethroscopy with injection of chemodenervation agent (bladder botulinum toxin), with the drug billed separately by HCPCS code and units
- **`64566`** — posterior tibial nerve stimulation (PTNS), billed per session
- **`64561`, `64581`, `64590`** and related codes — sacral neuromodulation trial, lead placement and generator implantation

These therapies often require prior authorization and documentation of failed conservative treatment, which our [eligibility verification](/eligibility-verification) team handles before the first session.

## Diagnosis coding

Accurate, specific diagnosis codes support medical necessity for reconstructive surgery and therapies:

- **`N81.-`** — female genital prolapse: cystocele (`N81.1-`), incomplete and complete uterovaginal prolapse (`N81.2`, `N81.3`), rectocele (`N81.6`), enterocele (`N81.5`)
- **`N99.3`** — prolapse of vaginal vault after hysterectomy
- **`N39.3`** — stress incontinence; **`N39.41`** urge; **`N39.46`** mixed
- **`N32.81`** — overactive bladder
- **`T83.-`** — complications of genitourinary prosthetic devices, including mesh

## Medicare patients

Urogynecology practices often see a high share of Medicare and Medicare Advantage patients. That brings specific requirements — Medicare's NCCI edits, local coverage determinations for therapies like neuromodulation, and Medicare Advantage prior authorization. We apply them on every claim.

## Documentation tips for reconstructive pelvic surgery

The operative note decides how much of a multi-procedure case can be billed. These details make the biggest difference:

- **Name each compartment repaired** — anterior, posterior, apical — and the technique used for each.
- **Describe the apical support procedure specifically** (sacrospinous, uterosacral, sacrocolpopexy) so the correct colpopexy code can be selected.
- **Document mesh or graft use** and the compartment where it was placed.
- **State the indication for any separately reported cystoscopy** if it was performed for a reason beyond routine intraoperative bladder and ureteral assessment.
- **Record uterine weight** from pathology when a hysterectomy is part of the case.
- **Note unusual difficulty** — dense adhesions, prior repairs, significantly increased time — if modifier `22` may be considered.

We provide feedback to surgeons when a note doesn't support the full set of procedures performed. Small documentation changes often make the difference between a fully paid case and a partially paid one.

## Common urogynecology coding errors

| Error | Correct approach |
|---|---|
| `57240` + `57250` billed for the same session | Report combined repair `57260` (or `57265` with enterocele repair) |
| Vaginal hysterectomy and repair billed separately | Check for the combination hysterectomy-with-repair code first |
| Intraoperative cystoscopy billed with sling or prolapse repair | Usually bundled; report only with a distinct documented indication |
| Laparoscopic sacrocolpopexy coded as open | Laparoscopic and robotic apical suspension is `57425` |
| Urodynamic components billed when not all were performed | Bill only the components documented in the study report |
| Mesh complication coded with a prolapse diagnosis only | Add the specific `T83.-` complication code |

## Authorization and medical necessity

Many payers apply clinical criteria to prolapse surgery, slings and especially to third-line therapies like sacral neuromodulation and bladder chemodenervation — often requiring documentation of symptom severity, duration and failed conservative measures such as pelvic floor physical therapy or medication trials. We gather that documentation before submitting authorization requests, which shortens approval times and reduces post-service denials.
